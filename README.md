# Catan · Banegenerator

Grafisk banegenerator til Catan for 3–4 og 5–6 spillere med valgfrie afstandskrav.

## Mobilapp

Statisk PWA med lokale data, manifest, PNG-ikoner og service worker. Ingen konto eller server er nødvendig.

GitHub Pages: main, / (root). Alle stier er relative.

Åbn i Chrome på Android og vælg Installér app. Safari på iPad: Del → Føj til hjemmeskærm.

Banen gemmes i browseren på den aktuelle enhed.

Uofficielt hjælpeværktøj. CATAN er et varemærke tilhørende den respektive rettighedshaver.
